## Atividade prática — Dicionário de Dados

Nesta atividade, você deverá **dar continuidade ao sistema de aeroporto desenvolvido na aula anterior**, utilizando o modelo de dicionário de dados fornecido.

### O que fazer

1. **Utilize as tabelas do sistema de aeroporto** que você definiu na aula anterior.
2. Caso necessário, **revise ou ajuste o modelo** antes de iniciar a documentação.
3. Para **cada tabela**, documente:
   - Nome e descrição da tabela;
   - Campos;
   - Tipo de dado;
   - Tamanho, quando aplicável;
   - Obrigatoriedade (`NULL` / `NOT NULL`);
   - Chave primária (PK);
   - Chave estrangeira (FK);
   - Valor padrão, quando houver;
   - Regras ou domínio dos valores;
   - Exemplos de valores.
4. Identifique e documente os **relacionamentos entre as tabelas**.
5. Descreva **pelo menos 3 regras de negócio** do sistema.
6. Documente os **índices e restrições**, quando aplicável.
7. Utilize o **modelo de Dicionário de Dados fornecido** para organizar a documentação.

### Importante

O objetivo não é criar um novo banco de dados.

**A atividade consiste em transformar o modelo de dados do sistema de aeroporto desenvolvido na aula anterior em uma documentação técnica completa.**

Ao final, o dicionário deve permitir que outra pessoa consiga compreender a estrutura e as regras do banco **sem precisar consultar diretamente o código ou o banco de dados**.
