# Atividade Prática 01 - Conceito de Dado e Informação

## Objetivo

Aplicar os conceitos de **dado** e **informação** estudados em sala por meio da análise de um sistema real.

---

# Cenário

Uma empresa foi contratada para desenvolver um **Sistema de Gerenciamento de Aeroporto**.

Antes de iniciar o desenvolvimento, é necessário compreender quais **dados** deverão ser armazenados e quais **informações** o sistema deverá ser capaz de fornecer aos seus usuários.

Nesta atividade, você atuará como analista responsável por esse levantamento inicial.

> **Importante:** Nesta etapa não é necessário criar banco de dados, diagramas ou código. O foco é apenas identificar dados e informações.

---

# Entrega

Crie um repositório no GitHub chamado:

```
atividade-01-aeroporto
```

O repositório deverá conter um arquivo chamado:

```
README.md
```

Toda a atividade deverá ser desenvolvida utilizando **Markdown**.

---

# Atividade

## 1. Levantamento dos dados

Liste os dados que você acredita que o sistema precisará armazenar.

Organize os dados em grupos que façam sentido.

Exemplo:

- Dados dos passageiros
- Dados dos voos
- Dados das aeronaves
- Dados das companhias aéreas
- Dados das bagagens
- Dados dos funcionários

Para cada grupo, descreva quais dados seriam necessários.

> Não existe uma resposta única. Utilize seu conhecimento e sua capacidade de análise.

---

## 2. Informações que o sistema deverá fornecer

Liste **pelo menos 15 informações** que poderão ser obtidas a partir dos dados armazenados.

Exemplos:

- Próximos voos do dia.
- Voos atrasados.
- Lista de passageiros de um voo.
- Histórico de viagens de um passageiro.
- Quantidade de bagagens por voo.
- Portão de embarque de cada voo.

---

## 3. Dados indispensáveis

Escolha **10 dados** que você considera essenciais para o funcionamento do sistema.

Para cada um deles, explique em uma ou duas linhas por que ele é importante.

---

## 4. Perguntas para o cliente

Antes de iniciar o desenvolvimento de qualquer sistema, é comum realizar uma reunião de levantamento de requisitos.

Imagine que você poderá conversar com o cliente responsável pelo aeroporto.

Elabore **10 perguntas** que ajudariam a compreender melhor o funcionamento do sistema.

Exemplos:

- Como funciona o processo de check-in?
- Existe limite de bagagens por passageiro?
- Um passageiro pode remarcar um voo?
- Como será controlado o embarque?

---

## 5. Reflexão

Responda às perguntas abaixo:

- Qual foi a maior dificuldade encontrada durante a atividade?
- Você acredita que seja possível desenvolver um sistema sem realizar esse levantamento inicial? Justifique sua resposta.
